# FlexSpGEMM AE archive

The archive contains the A100 experiment drivers, patches, models and evaluation inputs. See the ae-reproduction-guide branch for installation and experimental limitations. The original SuiteSparse matrices and the base LLM weights are downloaded separately.

Requires Git LFS. After cloning this branch, run `git lfs pull` and `sha256sum -c FlexSpGEMM-AE-github.tar.gz.sha256`.
